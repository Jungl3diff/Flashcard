Organizando elementos com Flexbox

O Flexbox permite organizar elementos em uma dimensão, controlando alinhamento, espaçamento e distribuição dos elementos dentro de um container.

.cabecalho { display: flex; align-items: center; justify-content: space-between; gap: 1rem; }

Conceitos de Flexbox

Propriedades utilizadas

01

display: flex

Transforma o elemento em um container Flexbox e permite organizar seus filhos de maneira flexível.

02

align-items

Controla o alinhamento dos elementos no eixo transversal do container.

03

justify-content

Controla como os elementos são distribuídos no eixo principal.

04

gap

Define o espaço entre os elementos sem depender de margens individuais.

05

flex-wrap

Permite que os elementos passem para outra linha quando o espaço disponível não for suficiente.

06

flex-direction

Define a direção do eixo principal, como linha ou coluna.
